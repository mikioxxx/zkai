# 無法地帯

## 編集・公開

- 本文: `dist/index.html`
- デザイン: `dist/style.css`
- 画像: `dist/assets/`
- ビルド不要。Netlify に手動公開する場合は、このサイトの `dist` を別サイトにアップロード。
- Sites の専用 ID は、このフォルダの `.openai/hosting.json` に保存。
